# Entering Beirut — site analysis

ARC 531-13 Design Studio VII, Fall 2026. A field-survey tool built on the instructor's cadastral
survey of Bourj Hammoud (`BOURJ HAMMOUD.dwg`), georeferenced EPSG:22780 → WGS84 and cropped to
580 × 496 m around the project plot.

Open the live page on a phone, tap **Field**, and record buildings, greenery, streets, arrival
points and views as you walk. Records attach to the section they belong to, take a photo, and
export as one JSON file.

The page is a single self-contained HTML file — Leaflet and the whole survey are inlined, so it
works with no network once loaded.
